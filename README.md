# 📋 Atividades Web Responsivo

Aplicação web responsiva para gerenciamento de atividades/tarefas, desenvolvida com HTML, CSS e JavaScript puro.

## 🎯 Sobre o projeto

O projeto permite que o usuário visualize uma lista de atividades e cadastre novas tarefas através de um formulário, informando o nome da atividade, dia e horário. As datas são formatadas em português utilizando a biblioteca [Day.js](https://day.js.org/).

## ✨ Funcionalidades

- Marcação de atividades como concluídas (checkbox)
- Formulário para adicionar novas atividades
- Seleção de dia e horário da atividade
- Formatação de datas em português (pt-BR)
- Layout responsivo, adaptado a diferentes tamanhos de tela

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura da página
- **CSS3** — estilização e responsividade
- **JavaScript** — lógica de manipulação do DOM e interatividade
- **Day.js** — formatação e manipulação de datas
